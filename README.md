# ece-128-lab-9
ECE 128 Lab 9. Design and Implementation of two RAMs and two ROMs, one of each using a file and one not using a file in Verilog using Vivado

### Project Description
We were tasked with designing memory modules in Verilog, specifically a RAM and a ROM, each in two versions: one where the stored values are defined directly in the code, and one where they are loaded from a text file. To accomplish this, we created a RAM design and a ROM design that store values at addresses 0-7. For the RAM, the values are written to each address through the testbench, while for the ROM, the values are defined within the design file itself. We then created file-based versions of each, in which the stored values are read from a text file that can be edited without changing the Verilog code. To verify the designs, we wrote a testbench for each of the four versions and ran the simulations in Vivado to confirm that the correct values appear at each address.

### Instructions
There are four potential simulations to create. The first one is the RAM with no text file. In order to run the simulation, the top simulation source in Vivado must be RAM_tb.v, with that done, all one must do is hit run simulation. The simulation will assign values 0-7 to the respective memory address from 0-7 as defined in the test bench. The next one is the RAM using a text file. To run the simulation for this one, the top simulation source in Vivado must be RAM_file_tb.v. The values associated with addresses 0-7 are defined in ram_data.txt and can be changed to whatever the user wants by editing the file with 8 bit binary values. All that's left to do is hit run simulation and simulation will assign whatever values written in ram_data.txt to addresses 0-7. The next simulation to create is for the ROM design. This design sets the value 0-7 to their respect address from 0-7, but directly in the design file. A user can directly edit the values in ROM.v to whatever they desire unlike the RAM design which would require more work in RAM_tb.v. Once the values are defined how the user wants, all they must do is hit run simulation with ROM_tb as the top simulation source. The simulation will have whatever values defined to their respect address. Finally, the last simulation to create is for the RAM design using a text file. Before running the simulation, the user can change the rom_data.txt file to use whatever 4 bit binary values they want. Once satisfied, the top simulation source must be set to ROM_file_tb.v and the simulation can be run.
